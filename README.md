# FoodieApp

FoodieApp is a simple Food Delivery Application developed using HTML, CSS and JavaScript.

## Features

- View food menu
- Add food to cart
- Calculate total
- Place order
- Responsive basic interface

## Agile User Stories

The application was developed using Agile principles and Jira Product Backlog.

- HTML
- CSS
- JavaScript
- Git
- GitHub
